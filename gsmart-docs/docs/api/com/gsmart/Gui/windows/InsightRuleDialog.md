# Classe: `InsightRuleDialog`

**Pacote:** `com.gsmart.Gui.windows`

## Descrição Geral

Uma janela de diálogo (JDialog) para criar ou editar uma `InsightRule`.  
Fornece um formulário para que o utilizador possa configurar todos os  
parâmetros de uma regra de alarme de forma intuitiva.

- **Ver Também:** com.gsmart.config.InsightRule
