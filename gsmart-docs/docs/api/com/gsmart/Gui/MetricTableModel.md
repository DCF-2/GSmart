# Classe: `MetricTableModel`

**Pacote:** `com.gsmart.Gui`

## Descrição Geral

Modelo de dados (TableModel) para a JTable que exibe as métricas.  
  
Esta classe interna gerencia a lista de objetos `MetricConfig`, controlando  
quais dados são exibidos na tabela e como eles podem ser editados pelo utilizador  
(seleção, alias e expressões).

- **Ver Também:** javax.swing.table.AbstractTableModel
- **Ver Também:** com.gsmart.config.MetricConfig
