# Classe: `AlertRuleTableModel`

**Pacote:** `com.gsmart.Gui`

## Descrição Geral

Modelo de dados (TableModel) para a JTable que exibe as regras de alerta.  
  
Esta classe faz a ponte entre a lista de objetos `AlertRule` e a  
tabela na interface gráfica, controlando como os dados são exibidos,  
formatados e editados pelo utilizador.

- **Ver Também:** com.gsmart.config.AlertRule
- **Ver Também:** javax.swing.table.AbstractTableModel
