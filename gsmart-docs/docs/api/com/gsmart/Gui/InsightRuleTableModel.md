# Classe: `InsightRuleTableModel`

**Pacote:** `com.gsmart.Gui`

## Descrição Geral

Modelo de dados (TableModel) para a JTable que exibe as regras de alarme.  
  
Esta classe faz a ponte entre a lista de objetos `InsightRule` e a  
tabela na interface gráfica, controlando como os dados são exibidos,  
formatados e editados pelo utilizador.

- **Ver Também:** com.gsmart.config.InsightRule
- **Ver Também:** javax.swing.table.AbstractTableModel
