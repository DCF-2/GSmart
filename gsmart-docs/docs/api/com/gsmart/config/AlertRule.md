# Classe: `AlertRule`

**Pacote:** `com.gsmart.config`

## Descrição Geral

Representa uma única regra de alerta configurável pelo utilizador.  
Contém todos os parâmetros necessários para avaliar uma condição e  
disparar uma notificação.
