\doxysubsection{Detailed Description}
Define uma interface de "{}ouvinte"{} para comunicação entre a lógica de pipeline e a interface do utilizador (UI).

As classes que implementam esta interface podem receber notificações em tempo real sobre eventos importantes que ocorrem dentro de uma {\ttfamily Data\+Pipeline}, como mudanças de estado, perda de conexão ou a geração de novos insights.
