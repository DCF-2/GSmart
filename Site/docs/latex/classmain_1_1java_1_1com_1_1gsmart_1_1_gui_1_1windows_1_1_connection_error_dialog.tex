\doxysubsection{Detailed Description}
Uma janela de diálogo não-\/modal que informa o utilizador sobre o estado da conexão de uma pipeline. 

Esta janela é exibida quando uma {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1pipeline_1_1_data_pipeline}{main.\+java.\+com.\+gsmart.\+pipeline.\+Data\+Pipeline}} perde a sua conexão com a fonte de dados. Ela fornece feedback visual sobre o estado (ex\+: "{}\+Falha de Conexão"{}, "{}\+Tentando reconectar em X segundos..."{}) e permite que o utilizador intervenha, forçando uma reconexão imediata ou cancelando a pipeline.
