\doxysubsection{Detailed Description}
Uma representação "{}salvável"{} da configuração de uma pipeline. 

Esta classe armazena os parâmetros necessários para reconstruir uma {\ttfamily \doxylink{interfacemain_1_1java_1_1com_1_1gsmart_1_1resources_1_1_i_data_source}{main.\+java.\+com.\+gsmart.\+resources.\+IData\+Source}} e uma {\ttfamily \doxylink{}{Pipeline\+Configuration}} completa, uma vez que a \doxylink{interfacemain_1_1java_1_1com_1_1gsmart_1_1resources_1_1_i_data_source}{IData\+Source} em si não pode ser serializada, permitindo que as sessões de pipeline sejam guardadas e restauradas.
