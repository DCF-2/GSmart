\doxysubsection{Detailed Description}
Representa os possíveis estados de uma tarefa de pipeline ({\ttfamily Pipeline\+Task}).

Esta enumeração define o ciclo de vida de uma tarefa, desde o seu início até à sua finalização, incluindo estados de erro e de paragem.
