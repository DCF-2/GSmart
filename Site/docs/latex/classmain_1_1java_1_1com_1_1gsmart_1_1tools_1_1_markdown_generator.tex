\doxysubsection{Detailed Description}
Ferramenta utilitária para gerar documentação em formato Markdown a partir dos comentários Javadoc do código-\/fonte.

Esta classe utiliza a biblioteca {\ttfamily \doxylink{}{com.\+github.\+javaparser.\+Java\+Parser}} para analisar os ficheiros .java do projeto, extrair os comentários Javadoc das classes e métodos, e convertê-\/los em ficheiros .md formatados, prontos para serem usados por geradores de sites estáticos como o Mk\+Docs.
