\doxysubsection{Detailed Description}
Apresenta a janela de login inicial da aplicação GSmart. 

Esta é a primeira janela que o utilizador vê e é responsável por autenticá-\/lo contra a base de dados local. Em caso de sucesso, esta janela é fechada e a janela principal da aplicação ({\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1_g_smart_gui}{GSmart\+Gui}}) é aberta, passando o perfil de acesso do utilizador.
