Classe utilitária responsável por enviar dados para a API de Push do Microsoft Power BI.

Esta classe contém um método estático que formata o objeto de dados num payload JSON, conforme esperado pela API, e realiza uma requisição POST para o endpoint especificado, tratando a resposta do servidor.
