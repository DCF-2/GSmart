\doxysubsection{Detailed Description}
Implementação da interface {\ttfamily IData\+Source} para se conectar e interagir com uma instância da plataforma de IoT Things\+Board.

Esta classe utiliza a biblioteca Ok\+Http para realizar chamadas à API REST do Things\+Board para autenticação, busca de metadados (perfis de dispositivo, dispositivos) e coleta de dados de telemetria em tempo real.
