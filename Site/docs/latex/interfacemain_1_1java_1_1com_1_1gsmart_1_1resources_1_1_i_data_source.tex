\doxysubsection{Detailed Description}
Define o contrato para todas as fontes de dados do sistema GSmart.

Qualquer classe que represente uma fonte de dados, como um banco de dados ou uma API de IoT, deve implementar esta interface. Isso garante que a {\ttfamily Data\+Pipeline} possa interagir com qualquer fonte de forma padronizada, promovendo a extensibilidade do sistema.
