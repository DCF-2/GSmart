\doxysubsection{Detailed Description}
Uma janela de UI que exibe os logs gerais da aplicação em tempo real. 

Esta classe redireciona as saídas padrão (System.\+out) e de erro (System.\+err) para um {\ttfamily \doxylink{}{JText\+Pane}}, permitindo que todos os logs gerados pela aplicação sejam visualizados numa única interface. As mensagens são coloridas com base no nível do log (INFO, WARN, ERROR) para facilitar a leitura.
