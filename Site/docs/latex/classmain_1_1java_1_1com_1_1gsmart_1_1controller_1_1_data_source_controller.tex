\doxysubsection{Detailed Description}
Controlador responsável por toda a lógica de interação com as fontes de dados. 

Esta classe isola a {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1_g_smart_gui}{main.\+java.\+com.\+gsmart.\+GSmart\+Gui}} dos detalhes de implementação de como se conectar e obter metadados (como listas de dispositivos, perfis, tabelas e métricas) das diferentes fontes de dados suportadas, como o Things\+Board e bases de dados JDBC. 

Utiliza {\ttfamily \doxylink{}{javax.\+swing.\+Swing\+Worker}} para executar operações de rede em segundo plano, evitando que a interface do utilizador bloqueie durante as conexões.
