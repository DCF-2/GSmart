\doxysubsection{Detailed Description}
Representa uma tarefa de pipeline completa e o seu estado atual.

Esta classe atua como um contentor que agrupa todos os elementos associados a um único processo de monitorização\+: a thread de execução, a instância da pipeline, a configuração original e as janelas de UI associadas (monitorização e erro).

É o principal objeto gerido pelo {\ttfamily Pipeline\+Manager}.

Orquestra uma paragem graciosa e completa da tarefa e dos seus componentes. 

A sequência de paragem é a seguinte\+: 
\begin{DoxyEnumerate}
\item Sinaliza para a instância da {\ttfamily Data\+Pipeline} que ela deve encerrar o seu loop. 
\item Interrompe a thread da pipeline para acordá-\/la de qualquer estado de espera (sleep). 
\item Fecha e remove as janelas de UI associadas (monitor e diálogo de erro). 
\item Executa o callback para notificar o {\ttfamily Pipeline\+Manager} que a tarefa foi removida. 
\item Define o estado final como FINISHED. 
\end{DoxyEnumerate}
