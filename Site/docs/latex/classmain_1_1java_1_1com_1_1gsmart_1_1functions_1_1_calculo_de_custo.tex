\doxysubsection{Detailed Description}
Classe utilitária para calcular o custo de consumo de energia. 

Esta classe mantém o estado do último valor de consumo de energia registado para calcular o custo incremental (delta) entre as medições. Inclui também um placeholder para uma futura integração com APIs de tarifas de energia,

Calcula o custo do consumo de energia desde a última medição. 

Este método é stateful\+: ele armazena o último valor total de consumo para calcular a diferença (delta) na chamada seguinte. Se o medidor for reiniciado (valor atual menor que o anterior), o cálculo é reiniciado.
