\doxysubsection{Detailed Description}
Implementação da interface {\ttfamily IData\+Source} para se conectar e interagir com um banco de dados relacional através de JDBC.

Esta classe é projetada para buscar o registo mais recente de uma tabela específica, simulando uma fonte de dados de telemetria. Ela lida com a conexão, execução de queries e formatação dos resultados para o formato JSON esperado pela pipeline.
