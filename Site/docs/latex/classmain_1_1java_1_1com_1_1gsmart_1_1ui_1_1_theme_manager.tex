\doxysubsection{Detailed Description}
Gestor central para a aplicação de temas (Look and Feel) na UI. 

Esta classe utiliza a biblioteca Flat\+Laf para gerir e aplicar temas visuais (claro, escuro, padrão do sistema) a toda a aplicação. É também responsável por guardar a preferência de tema do utilizador para que seja restaurada em sessões futuras.
