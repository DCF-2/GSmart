\doxysubsection{Detailed Description}
Classe utilitária responsável por enviar dados para um Fluxo de Eventos (Eventstream) do Microsoft Fabric.

Esta classe utiliza o SDK do Azure Event Hubs para se conectar de forma segura ao endpoint fornecido pelo Fabric e enviar os dados da pipeline como eventos em formato JSON.
