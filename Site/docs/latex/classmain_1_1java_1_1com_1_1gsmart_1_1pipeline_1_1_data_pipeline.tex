\doxysubsection{Detailed Description}
Representa o motor de uma única pipeline de processamento de dados.

Esta classe é responsável pelo ciclo de vida completo de uma tarefa de monitorização\+: 
\begin{DoxyEnumerate}
\item {\bfseries{Busca de Dados\+:}} Conecta-\/se a uma {\ttfamily \doxylink{interfacemain_1_1java_1_1com_1_1gsmart_1_1resources_1_1_i_data_source}{main.\+java.\+com.\+gsmart.\+resources.\+IData\+Source}} para obter os dados de telemetria mais recentes. 
\item {\bfseries{Processamento e Transformação\+:}} Aplica as configurações de métricas ({\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1config_1_1_metric_config}{main.\+java.\+com.\+gsmart.\+config.\+Metric\+Config}}), como aliases e expressões matemáticas. 
\item {\bfseries{Avaliação de Regras\+:}} Executa o motor de regras para verificar se alguma {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1config_1_1_alert_rule}{main.\+java.\+com.\+gsmart.\+config.\+Alert\+Rule}} ou {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1config_1_1_insight_rule}{main.\+java.\+com.\+gsmart.\+config.\+Insight\+Rule}} foi despoletada. 
\item {\bfseries{Notificação\+:}} Comunica alertas e insights através do {\ttfamily \doxylink{interfacemain_1_1java_1_1com_1_1gsmart_1_1resources_1_1_g_smart_listener}{main.\+java.\+com.\+gsmart.\+resources.\+GSmart\+Listener}} e envia notificações para serviços externos como MQTT e Telegram. 
\item {\bfseries{Exportação de Dados\+:}} Envia os dados processados para destinos como Power BI ou Microsoft Fabric. 
\item {\bfseries{Gestão de Conexão\+:}} Lida com a lógica de reconexão automática em caso de falha na comunicação com a fonte de dados. 
\end{DoxyEnumerate}Cada instância desta classe é executada na sua própria thread, gerida por uma {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1pipeline_1_1_pipeline_task}{Pipeline\+Task}}.

Inicia e executa o ciclo de processamento contínuo da pipeline. 

Este método contém o loop principal que busca, processa e envia dados em intervalos regulares. Ele continuará a ser executado até que o método {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1pipeline_1_1_data_pipeline_a467670cc3a089af123318633ac9be9d3}{request\+Stop()}} seja chamado. 

Em caso de falha de conexão com a fonte de dados, este método entra num modo de reconexão automática, com um tempo de espera exponencial, até que a conexão seja restabelecida ou a tarefa seja interrompida. \Hypertarget{classmain_1_1java_1_1com_1_1gsmart_1_1pipeline_1_1_data_pipeline_a9a68783e7c1d032d4bf406c2ca11b06a}\index{main.java.com.gsmart.pipeline.DataPipeline@{main.java.com.gsmart.pipeline.DataPipeline}!triggerManualReconnect@{triggerManualReconnect}}
