\doxysubsection{Detailed Description}
Janela de diálogo para criar um novo utilizador ou editar um existente. 

Apresenta um formulário com campos para o nome de utilizador, senha e perfil de acesso. Esta janela é utilizada pela {\ttfamily \doxylink{classmain_1_1java_1_1com_1_1gsmart_1_1_gui_1_1windows_1_1_user_management_window}{User\+Management\+Window}} para gerir o ciclo de vida dos utilizadores do sistema.
