Detailed Description

Modelo de dados (TableModel) para a JTable que exibe as métricas disponíveis.

Esta classe gere a lista de objetos main.java.com.gsmart.config.MetricConfig, controlando quais dados são exibidos na tabela e como eles podem ser editados pelo utilizador (seleção, alias e expressões matemáticas).
