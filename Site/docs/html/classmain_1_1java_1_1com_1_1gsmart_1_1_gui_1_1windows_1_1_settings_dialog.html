Detailed Description

Janela de diálogo para as configurações gerais da aplicação GSmart.

Permite ao utilizador configurar o comportamento da aplicação, como a opção de executar em segundo plano, e fornece um atalho para a gestão das pipelines de início automático. As configurações são carregadas no arranque da janela e guardadas quando esta é fechada.
