Gsmart V.6.0
GSmart é uma aplicação de desktop em Java que extrai dados de fontes de IoT, como o ThingsBoard e bancos de dados. A aplicação processa essas informações para gerar análises e, em seguida, envia os resultados para plataformas de Business Intelligence como o Power BI.
