Detailed Description

Painel de navegação lateral retrátil para a aplicação GSmart.

Este painel contém os botões para navegar entre as diferentes secções da aplicação (Dashboard, Configuração, Regras), bem como atalhos para ações rápidas e funções de gestão. O painel pode ser expandido ou recolhido para otimizar o espaço no ecrã.
