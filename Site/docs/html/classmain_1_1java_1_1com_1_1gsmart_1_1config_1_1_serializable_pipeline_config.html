Detailed Description

Uma representação "salvável" da configuração de uma pipeline.

Esta classe armazena os parâmetros necessários para reconstruir uma main.java.com.gsmart.resources.IDataSource e uma PipelineConfiguration completa, uma vez que a IDataSource em si não pode ser serializada, permitindo que as sessões de pipeline sejam guardadas e restauradas.
