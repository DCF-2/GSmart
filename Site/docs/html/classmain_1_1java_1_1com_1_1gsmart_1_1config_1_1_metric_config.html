main.java.com.gsmart.config.MetricConfig.MetricConfig ( String originalName,
boolean isSelected,
boolean isSystem )

Constrói uma configuração detalhada para uma única métrica a ser processada pela pipeline.

Esta classe contém todos os detalhes sobre como uma métrica específica, vinda da fonte de dados, deve ser selecionada, transformada e nomeada. Uma lista destes objetos é usada pela DataPipeline para construir o payload final.

Parameters
originalNameO nome da métrica tal como vem da fonte de dados (ex: "temperature").
isSelectedDefine se esta métrica deve ser processada e enviada para o destino.
isSystemDefine se esta é uma métrica gerada pelo sistema (ex: "timestamp") e não pela fonte de dados.
