Detailed Description

Representa uma única regra de alerta configurável pelo utilizador. Contém todos os parâmetros necessários para avaliar uma condição e disparar uma notificação.

Parameters
ruleNameO nome descritivo da regra para identificação na UI.
metricToWatchA métrica (nome original) que esta regra irá monitorizar.
conditionO tipo de comparação a ser feita (ex: MAIOR_QUE, MENOR_QUE).
thresholdValueO valor limiar contra o qual a métrica será comparada.
messageToSendA mensagem de notificação a ser enviada quando a regra for despoletada.
sendToMqttSe true, a notificação será enviada para o broker MQTT.
sendToTelegramSe true, a notificação será enviada para o Telegram.
