Detailed Description

Apresenta a janela de login inicial da aplicação GSmart.

Esta é a primeira janela que o utilizador vê e é responsável por autenticá-lo contra a base de dados local. Em caso de sucesso, esta janela é fechada e a janela principal da aplicação (GSmartGui) é aberta, passando o perfil de acesso do utilizador.

Constrói e inicializa a janela de login, montando todos os seus componentes visuais.

O design é dividido em dois painéis: um painel esquerdo para a marca (logo) e um painel direito que contém o formulário de autenticação.
