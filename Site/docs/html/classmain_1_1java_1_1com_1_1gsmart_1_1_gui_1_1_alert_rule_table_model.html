Detailed Description

Modelo de dados (TableModel) para a JTable que exibe as regras de alerta.

Esta classe faz a ponte entre a lista de objetos main.java.com.gsmart.config.AlertRule e a tabela na interface gráfica, controlando como os dados são exibidos, formatados e editados pelo utilizador.
