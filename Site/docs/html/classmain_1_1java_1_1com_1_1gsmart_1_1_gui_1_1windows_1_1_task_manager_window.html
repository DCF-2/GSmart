Detailed Description

Uma janela (JFrame) que funciona como a "Central de Monitoramento".

Ela exibe uma tabela (JTable) com todas as tarefas de pipeline ativas, mostrando informações cruciais como seu estado, descrição e tempo de execução. Esta classe comunica-se com o PipelineManager para receber atualizações em tempo real e permite que o utilizador interaja com as tarefas (visualizar, parar ou reiniciar) diretamente pela interface.
