Detailed Description

Renderizador de células customizado para a tabela de métricas.

A sua principal função é alterar a aparência (fonte e cor) das métricas que são consideradas "de sistema" (como timestamp), diferenciando-as visualmente das métricas normais para uma melhor legibilidade.
