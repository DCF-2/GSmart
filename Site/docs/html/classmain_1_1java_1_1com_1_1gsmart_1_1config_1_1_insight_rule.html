Detailed Description

Representa uma única regra configurável para a geração de "Alarmes" (anteriormente "Insights").

Esta classe permite definir uma condição baseada numa métrica que, quando satisfeita, gera uma mensagem inteligente e categorizada, fornecendo observações proativas sobre o estado do sistema.
