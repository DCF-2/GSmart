Detailed Description

Classe de serviço responsável por enviar mensagens para a API do Telegram.

Esta classe utilitária fornece um método estático para encapsular a lógica de realizar requisições HTTP para o endpoint de envio de mensagens do Telegram, tratando da formatação da URL e do corpo da requisição.
