Detailed Description

Uma janela de diálogo não-modal que informa o utilizador sobre o estado da conexão de uma pipeline.

Esta janela é exibida quando uma main.java.com.gsmart.pipeline.DataPipeline perde a sua conexão com a fonte de dados. Ela fornece feedback visual sobre o estado (ex: "Falha de Conexão", "Tentando reconectar em X segundos...") e permite que o utilizador intervenha, forçando uma reconexão imediata ou cancelando a pipeline.

Inicia uma contagem decrescente, mostrando ao utilizador o tempo até à próxima tentativa de reconexão.
