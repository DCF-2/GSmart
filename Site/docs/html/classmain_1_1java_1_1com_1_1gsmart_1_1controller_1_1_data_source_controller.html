Detailed Description

Controlador responsável por toda a lógica de interação com as fontes de dados.

Esta classe isola a main.java.com.gsmart.GSmartGui dos detalhes de implementação de como se conectar e obter metadados (como listas de dispositivos, perfis, tabelas e métricas) das diferentes fontes de dados suportadas, como o ThingsBoard e bases de dados JDBC.

Utiliza javax.swing.SwingWorker para executar operações de rede em segundo plano, evitando que a interface do utilizador bloqueie durante as conexões.

◆ createSelectedDataSource()

IDataSource main.java.com.gsmart.controller.DataSourceController.createSelectedDataSource ( List< String > originalKeys) throws Exception

Cria e retorna uma instância da main.java.com.gsmart.resources.IDataSource com base nas configurações selecionadas na interface do utilizador.

Este método funciona como uma "fábrica" (factory), lendo a seleção atual da UI para instanciar e configurar o objeto de fonte de dados correto (seja main.java.com.gsmart.sources.ThingsBoardSource ou main.java.com.gsmart.sources.DatabaseSource) que será usado pela pipeline. Antes de retornar, testa a conexão com a fonte de dados para garantir que está operacional.

Parameters
originalKeysA lista de nomes de métricas originais que a fonte de dados deve buscar.
Returns
Uma instância configurada e pronta a usar da IDataSource.
Exceptions
Exceptionse a fonte de dados selecionada for inválida, se faltar alguma configuração ou se o teste de conexão falhar.

Carrega de forma assíncrona as métricas (chaves de telemetria ou colunas de tabela) disponíveis para a fonte de dados selecionada.
