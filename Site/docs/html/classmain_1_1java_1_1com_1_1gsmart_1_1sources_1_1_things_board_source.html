Detailed Description

Implementação da interface IDataSource para se conectar e interagir com uma instância da plataforma de IoT ThingsBoard.

Esta classe utiliza a biblioteca OkHttp para realizar chamadas à API REST do ThingsBoard para autenticação, busca de metadados (perfis de dispositivo, dispositivos) e coleta de dados de telemetria em tempo real.
