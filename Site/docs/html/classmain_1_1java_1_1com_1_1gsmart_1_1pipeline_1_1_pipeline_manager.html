Detailed Description

Orquestrador central para o ciclo de vida de múltiplas tarefas de pipeline (PipelineTask).

Esta classe atua como o "maestro" do sistema, responsável por instanciar, gerir e finalizar os processos de monitorização de dados. Ela faz a ponte entre as configurações definidas na main.java.com.gsmart.GSmartGui e a execução real das DataPipeline em threads separadas.

Principais Responsabilidades:

  • Lançar novas tarefas de pipeline com base numa main.java.com.gsmart.config.PipelineConfiguration.
  • Manter e fornecer uma lista atualizada de todas as tarefas em execução.
  • Gerir a comunicação entre a lógica de fundo (DataPipeline) e a interface gráfica (GUI).
  • Controlar a exibição de janelas de monitorização e diálogos de erro de conexão.
  • Fornecer métodos para reiniciar ou parar tarefas de forma segura.

◆ launchPipeline()

void main.java.com.gsmart.pipeline.PipelineManager.launchPipeline ( PipelineConfiguration config)

Lança uma nova pipeline com base numa configuração fornecida.

Este método instancia e configura todos os componentes necessários para uma nova tarefa de monitoramento, incluindo a DataPipeline, a Thread de execução e o listener de eventos, encapsulando tudo num objeto PipelineTask.

Antes de iniciar, verifica se já existe uma pipeline em execução para a mesma fonte de dados para evitar duplicados.

Parameters
configO objeto de configuração contendo todos os parâmetros necessários para o pipeline, como a fonte de dados, métricas e URL de destino.

◆ showMonitorFor()

void main.java.com.gsmart.pipeline.PipelineManager.showMonitorFor ( PipelineTask task)

Exibe a janela de monitorização para uma tarefa específica.

Se uma janela de monitorização para esta tarefa ainda não existir ou tiver sido fechada, uma nova é criada. Se já existir e estiver visível, a janela existente é trazida para a frente, garantindo que apenas uma instância do monitor seja exibida por tarefa.
