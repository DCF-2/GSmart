Detailed Description

Janela de diálogo para criar um novo utilizador ou editar um existente.

Apresenta um formulário com campos para o nome de utilizador, senha e perfil de acesso. Esta janela é utilizada pela UserManagementWindow para gerir o ciclo de vida dos utilizadores do sistema.
